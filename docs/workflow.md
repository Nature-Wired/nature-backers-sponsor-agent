# Sponsor Agent Workflow

## Guided Setup Principle

The current Nature Backers campaign flow requires manual setup: campaign details are entered by hand, projects are filtered manually, and the ballot is assembled through the admin interface.

The AI Sponsor Agent improves this by guiding the sponsor or admin through a lighter setup flow and generating the first campaign draft automatically.

The agent should not replace human review. It should reduce manual work before review.

The guided flow is:

1. User provides rough campaign context.
2. AI generates campaign draft.
3. AI recommends a 3-project ballot from Guardian Indexer data where available.
4. Human sponsor/admin reviews and approves.
5. Approved campaign details can move into the existing Nature Backers workflow.

## 1. Campaign Setup

User provides:
- Sponsor name
- Event type
- Location
- Audience size
- Funding amount
- Campaign goal
- Project preferences

## 2. AI Campaign Recommendation

Agent generates:
- Campaign name
- Sponsor story
- Fan participation concept
- Suggested project themes
- Suggested vote/funding logic

## 3. Project Ballot

Agent recommends 3 projects or project themes.

Example:
1. Bay wetlands restoration
2. Urban tree canopy / heat resilience
3. Coastal biodiversity / marine habitat

## 4. Sponsor Approval

Sponsor reviews and approves:
- Campaign concept
- Project ballot
- Funding logic
- Public-facing message

## 5. Hedera Recording

After approval, Hedera Agent Kit may record:
- Campaign ID
- Approved ballot
- Timestamp
- Participation totals
- Funding allocation summary

## 6. Post-Event Report

Agent generates:
- Fan participation summary
- Winning project
- Allocation breakdown
- Sponsor storytelling copy
- Proof points for reporting
