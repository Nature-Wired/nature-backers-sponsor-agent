# Nature Backers Sponsor Agent

AI-powered sponsor workflow agent for participatory sustainability campaigns tied to women’s sports and local nature-based projects.

## What This Builds On

This project builds on the Nature Backers Apex Hackathon prototype, which demonstrated QR-based fan participation, project voting, HCS participation records, proof-of-participation token concepts, and sponsor dashboards.

## What Is New

This repository focuses on the AI agent layer.

The Sponsor Agent helps a sponsor:
- define campaign goals
- generate a fan engagement concept
- recommend project themes
- propose voting and participation thresholds
- outline reporting metrics
- prepare lightweight Hedera interaction steps
